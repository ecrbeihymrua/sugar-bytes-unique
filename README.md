## Overview

Sugar Bytes Unique is a modular-inspired polyphonic synthesizer where oscillators, filters, and effects can be freely connected in custom signal paths for deep sound design.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sugar Bytes Unique** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Modular Routing** | Freely connect any module output to any other module input |
| **Oscillator Bank** | Multiple oscillator types: wave, FM, phase mod, and noise |
| **Filter Matrix** | Connect multiple filters in series, parallel, or feedback configurations |
| **Poly Mode** | Up to 16-voice polyphony with per-voice modulation routing |
